# 유물 원형과 보드 미리보기

- 상태: approved
- 관련 결정: `DEC-20260728-03`
- 승인 기록: 2026-07-28 사용자가 유물 원형의 종류·내구도 설정과 배치 지점 미리보기를 승인함

## 승인된 경계

- 유물 원형은 안정적인 ID, 표시 이름과 최대 내구도 설정을 제공한다.
- 보드 템플릿은 유물 배치 지점과 호환 조건만 제공한다.
- 제작 화면은 유물 원형을 미리보기로 표시할 수 있지만 플레이어의 보유·실제 배치 상태를 만들지 않는다.
- 실제 유물 배치, 이동·교체·제거와 현재 내구도는 `relics/placement`와 후속 유물 런타임이 소유한다.
- 유물 배치 시점 D-06, 리트라이 초기화 D-03과 스테이지 간 유지 D-09를 이 단계에서 확정하지 않는다.

## 제품 리소스

- `RelicDefinition`은 유물 미리보기 원형의 안정적인 원형 ID, 표시 이름과 내구도 설정을 제공한다.
- 기본 유물 미리보기 샘플은 보드 제작 화면의 조립 확인용 데이터다. 플레이어의 보유 유물이나 실제 유물 배치 상태를 만들지 않는다.

## 수용 기준

1. 유물 미리보기를 바꿔도 보유·실제 배치 상태가 변하지 않는다.
2. 유물 원형과 유물 배치 지점의 호환성 오류를 조립 전에 거부한다.
3. 논리 유물 원형이 2D·3D 장면에 의존하지 않는다.
4. 실제 내구도 감소·파괴·복구는 후속 8단계까지 `미검증`으로 기록한다.
