# 일반 웨이브 스코어 목표

- 상태: approved
- 관련 결정: `DEC-20260729-07`, D-01, D-02

- 목표 스코어는 양의 정수이며 웨이브가 참조하는 `.tres`로 제공한다.
- 기본 목업 목표는 1,000점이며 밸런스 확정값이 아니라 복제 설정으로 교체하는 기본값이다.
- 현재 스코어가 목표 이상이어도 공이 진행 중이면 웨이브를 종료하지 않는다.
- 공 낙하 뒤 현재 스코어가 목표 이상이면 웨이브 클리어, 미달이고 공이 남으면 다음 공 선택, 미달이고 남은 공이 0개면 스테이지 실패 후보를 확정한다.
- 같은 발사 결과와 종료된 웨이브의 중복 판정은 상태를 바꾸지 않는다.

## 수용 기준

1. 0·음수·누락된 목표를 플레이 전에 거부한다.
2. 목표 미만·같음·초과를 낙하 뒤 정확히 비교한다.
3. 목표 초과 중 추가 점수를 허용하고 낙하 뒤 결과 하나만 확정한다.
4. 마지막 공의 마지막 타격을 반영한 뒤에만 실패 여부를 결정한다.
