## 구현 내용

- 사용자가 승인한 계획의 1단계만 수행했다.

- 58° 경사 원근과 16:9 고정 화면을 기준으로 산업 호러 핀볼 보드 목업 v1을 생성했다.
- 일반 범퍼 4개, 바운스 범퍼 1개, 플리퍼 2개, 상단 보스, 발사 공, 중앙 드레인과 유물 슬롯 3개를 한 화면에 배치했다.

## 구현 결과

- 결과 이미지는 1672×941px이며 16:9 화면비다.
- 일반 범퍼는 금속 톱날 허브, 바운스 범퍼는 옅은 청색 코일, 보스 약점은 주황 코어, 플리퍼는 곰덫 턱 실루엣으로 구분된다.
- 살점, 내장, 피와 핏자국을 사용하지 않고 기계 실루엣과 조명만으로 위압감을 표현했다.
- 기본 이미지에 불꽃, 스파크, 파편, 연기와 충돌 효과를 넣지 않았다.
- v2는 사실적인 PBR 재질과 텅스텐 광원 표현을 제거하고 굵은 외곽선, 평면 도형과 2~3단계 셀 명암으로 변경했다.
- v2에서도 오브젝트 개수, 경로와 기능 강조색을 유지했다.

## 트러블슈팅

- 증상: 원본 상세 모드의 첫 로컬 미리보기에서 화면 대부분이 검게 표시됐다.
- 재현: `view_image`를 `detail=original`로 열었을 때 발생했다.
- 원인: 로컬 미리보기의 원본 상세 렌더링 문제로 판단했으며 실제 파일과 축소 이미지에는 이상이 없었다.
- 해결: `detail=high`로 다시 열어 전체 이미지를 확인했다.
- 재검증: 전체 보드, 오브젝트와 조명이 정상 표시됨을 확인했다.
