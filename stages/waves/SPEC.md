# 웨이브 보드 배치

- 상태: approved
- 관련 결정: `DEC-20260728-03`
- 승인 기록: 2026-07-28 사용자가 배치 지점과 실제 오브젝트 배치를 분리하고 웨이브별 플리퍼 1~4개와 원형 교체를 승인함

## 목적과 사용자 경험

기획자는 같은 보드 템플릿을 여러 웨이브에 재사용하면서 각 배치 지점의 범퍼·벽·일반 오브젝트와 플리퍼 디자인을 다르게 연결한다. 지점 위치를 수정하면 연결된 오브젝트가 따라가고, 원형을 교체하면 위치는 유지된다.

## 승인된 동작

- 웨이브 배치는 보드 템플릿 하나와 배치 지점별 오브젝트 원형 연결을 소유한다.
- 빈 지점은 허용하며 실제 오브젝트를 생성하지 않는다.
- 지점 역할과 원형 종류가 일치해야 한다.
- 한 웨이브에는 플리퍼 원형이 연결된 외곽선 지점이 1~4개 있어야 한다.
- 경로 범퍼 배치는 보드의 `경로 지점`을 순서대로 연결하고, 발사 범퍼 배치는 보드의 `발사 목표 지점` 하나를 연결한다. 보조 지점의 실제 위치는 보드 제작 화면에서 마우스로 수정한다.
- 실제 플레이어 유물은 고정 웨이브 배치가 아니라 런타임 유물 배치 상태가 연결한다. 제작 화면의 유물은 미리보기다.
- 공은 웨이브 보드 배치에 포함하지 않는다.
- 디버그 실행에서 사용할 현재 시험 보드는 전용 선택 설정 하나가 참조하며, 보드 제작 도구의 `웨이브에서 이 보드 시험` 조작으로 현재 웨이브 배치를 연결한다. 출시용 웨이브 데이터와 명시적 장면 덮어쓰기가 우선한다.

## 목업 웨이브 공 목록

- 웨이브 콘텐츠는 보드 고정 배치와 별도로 발사에 사용할 공 슬롯 1~3개를 제공한다.
- 각 슬롯은 고유 슬롯 ID와 공 원형을 참조한다. 같은 `standard_ball` 원형을 여러 슬롯이 사용해도 소모 상태는 슬롯별로 독립적이다.
- 공 슬롯은 보드 템플릿이나 웨이브 오브젝트 배치에 공 장면을 배치하지 않고 런타임 발사 조립 계층에 선택 가능한 목록만 전달한다.
- 4단계 기본 목업은 표준 공 슬롯 3개를 사용하며 이는 영구 기본 수량이나 획득 정책을 확정하지 않는다.

## 데이터와 상태

- 구성 데이터는 배치 지점 ID, 오브젝트 원형 ID와 범퍼가 참조할 경로·발사 목표 지점 ID만 저장하며 2D·3D 장면을 직접 참조하지 않는다.
- 같은 웨이브 배치의 현재 2D 조립과 미래 3D 조립은 동일한 지점·원형 연결을 소비한다.
- 런타임에서 생성된 오브젝트의 현재 내구도와 활성 상태는 웨이브 배치가 소유하지 않는다.

## 수용 기준

1. 같은 보드 템플릿에 서로 다른 두 웨이브 배치를 적용하면 독립적인 오브젝트 구성이 표시된다.
2. 없는 지점·원형, 중복 연결과 역할 불일치를 실행 전에 거부한다.
3. 플리퍼 1·2·3·4개 구성이 각각 저장·조립되고 0·5개는 거부된다.
4. 한 웨이브의 변경이 다른 웨이브와 기본 보드 템플릿을 바꾸지 않는다.
5. 공 관련 ID·원형·장면 참조가 없다.
6. 별도 공 목록은 1~3개만 허용하고 같은 공 원형을 사용하는 슬롯도 고유 슬롯 ID로 선택·소모된다.
7. 경로 범퍼는 하나 이상의 유효한 경로 지점을 순서대로 참조하고, 발사 범퍼는 유효한 발사 목표 지점 하나를 참조해야 한다. 다른 범퍼 종류에 남은 불필요한 경로·목표 연결은 조립 전에 거부한다.

## 미확정 사항

- 유물 런타임 배치 시점은 후속 유물 단계에서 확정한다.
