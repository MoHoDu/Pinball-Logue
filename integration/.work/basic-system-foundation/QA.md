### BUG-UNTRACKED-02 — 방향키 조준에서 길게 누르기가 반복 조절되지 않음

- 추적 상태: fixed-and-reverified
- 수정 전 재현: `direction_keys` 조준에서 방향키 최초 입력만 각도·세기에 반영되고 길게 누를 때의 반복 입력은 모두 무시됐다.
- 확정 원인: `Space` 중복 발사를 막기 위한 입력 반복 차단이 방향키 조준에도 일괄 적용됐다.
- 해결: `direction_keys` 조준 상태의 네 방향키 반복만 허용하고 `Space`, 공 선택, 플리퍼 선택과 키 해제 반복은 계속 차단했다.
- 재검증: 오른쪽 반복 2회가 각도 2단계, 위 반복 1회가 세기 1단계를 누적했다. `Space` 반복은 발사 0회였고 전체 자동 검사 15/15가 통과했다.
- Jira: 로컬에서 수정·재검증됐으며 사용자 요청이 없어 생성하지 않음

### BUG-UNTRACKED-01 — Web에서 한국어가 네모 글리프로 표시됨

- 1단계와 승인된 1A 보완의 정상·경계·회귀·Godot·Web 수용 기준은 모두 통과했다.
