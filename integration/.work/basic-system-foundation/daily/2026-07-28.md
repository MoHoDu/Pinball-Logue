## 구현 결과

- Godot 4.7.1 프로젝트 스캔, Desktop 런타임과 화면 전환 스모크가 종료 코드 0으로 통과했다.
- release Web export가 종료 코드 0으로 완료돼 HTML, JS, PCK, WASM과 아이콘 리소스 9개가 생성됐다.
- export 로그에서 Pretendard `.fontdata`, WOFF2 임포트 정보와 공용 Theme 패킹을 확인했다.
- Chromium에서 WASM·PCK 요청 HTTP 200, 콘솔 오류 0건·경고 0건과 화면 전체 한 주기 전환을 확인했다.
- 여섯 화면의 현재 한국어가 Pretendard로 정상 표시돼 `BUG-UNTRACKED-01`을 수정·재검증 완료했다.
- 1단계의 모든 승인 수용 기준이 통과했다.

## 트러블슈팅

- 증상: Codex 제한 환경에서 Godot 런타임이 Windows 접근 위반으로 종료됨.
- 원인: 같은 명령을 승인된 일반 실행 환경에서 수행하면 통과해 격리 환경 충돌로 분리했다.
- 해결·재검증: 승인된 일반 실행 환경에서 실행해 `SCENE_NAVIGATION_SMOKE: PASS`와 종료 코드 0을 확인했다.

- 증상: Web export가 템플릿 부재로 시작되지 않음.
- 원인: Godot 표준 경로에 버전 일치 Web 템플릿이 없었다.
- 해결·재검증: 사용자 승인 후 공식 4.7.1 Web 템플릿을 설치했고 release export 종료 코드 0을 확인했다.

- 증상: Chromium에서 한국어가 네모 글리프로 표시됨.
- 원인: 제품에 한국어 글리프를 제공하는 번들 폰트와 공용 Theme가 없었다.
- 해결: 승인된 Pretendard Regular와 라이선스를 제품 리소스에 포함하고 단일 공용 Theme를 여섯 화면에 적용했다.
- 재검증: Chromium 1280×720 전체 주기 1/1에서 여섯 화면의 현재 한국어가 정상 표시됐다.

## 사용자 기획·개발 변경으로 개선된 점

- 사용자 승인으로 정확한 Godot 4.7.1 Web 환경에서 실제 브라우저 동작을 검증했다.

- 공용 Theme 하나로 여섯 화면의 기본 폰트를 교체할 수 있게 됐다.
