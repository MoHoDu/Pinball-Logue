## 2단계 트러블슈팅

- 증상: 앱 통합 시나리오가 두 테스트 변수의 타입을 추론하지 못해 파싱 단계에서 종료 코드 1.

- 증상: 기존 `scene_foundation_editor_check.gd`를 `--script`로 실행할 수 없음.
- 원인: 명령행 진입점이 필요한 검사였지만 `EditorScript`를 상속하고 있었다.
- 해결·재검증: 같은 리소스·장면 검사를 `SceneTree` 진입점으로 바꿔 `SCENE_FOUNDATION_EDITOR_CHECK: PASS`를 확인했다.

- 원인: Godot Web UI가 HTML DOM 버튼이 아니라 캔버스에 렌더링된다.
- 해결·재검증: 시각 확인한 좌표에 Chromium 포인터 입력을 보내고 웨이브·보스·결과·다음 스테이지 화면을 캡처했다.
