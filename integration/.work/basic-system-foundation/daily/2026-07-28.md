## 3단계 트러블슈팅

- 증상: 첫 신규 테스트가 격리 환경의 `user://logs` 접근 실패 뒤 Godot 신호 11로 종료됐다.
- 원인: 프로젝트 코드가 아니라 macOS 사용자 로그 경로에 대한 격리 환경 권한 충돌이었다.
- 해결·재검증: 승인된 일반 실행 환경에서 동일한 Godot 4.7.1 명령을 실행해 테스트와 프로젝트 스캔을 완료했다.

- 증상: 신규 전역 클래스 등록 전 `--script` 실행에서 `BoardLayoutConfig`와 `BoardAnchorConfig` 타입을 찾지 못했다.
- 원인: 새 `class_name` 스크립트를 추가한 뒤 Godot 편집기 파일 스캔을 아직 실행하지 않았다.
- 해결·재검증: `--headless --editor --quit`로 전역 클래스를 등록한 뒤 신규 테스트를 재실행했다.

- 증상: `Geometry2D.segment_intersects_segment()` 반환값의 `Variant` 추론 경고가 오류로 처리됐다.
- 원인: 프로젝트의 경고 승격 조건에서 `:=`가 반환 타입을 확정하지 못했다.
- 해결·재검증: 반환 변수에 `Variant` 타입을 명시하고 신규 데이터 검사를 통과시켰다.

- 증상: 병렬 계약 감사에서 정규화 경계 범위 검사가 실제로 실행되지 않는 위음성을 발견했다.
- 원인: 비유한 좌표 처리용 `continue`가 조건문 밖에 있어 후속 범위·0길이 검사를 항상 건너뛰었다.
- 해결·재검증: 들여쓰기를 수정하고 경계점 `0.51` 거부 케이스를 추가해 자체·독립 QA에서 재통과했다.

- 증상: 코드 리뷰에서 에디터 씬 직접 로드 시 `BoardViewConfig`가 placeholder로 처리될 가능성과 플리퍼 회전의 원근 누락을 발견했다.
- 원인: 표현 Resource의 `@tool` 누락과 평면 회전값을 화면 회전으로 직접 사용한 구현이었다.
- 해결·재검증: `BoardViewConfig`를 도구 스크립트로 만들고 두 논리점을 투영해 화면 방향을 구하도록 변경했다. 에디터 씬 직접 로드와 플리퍼 방향 자동 단언을 통과했다.

## 3단계 에디터 사용성 재점검

- 사용자가 원하는 조립 경험은 보드를 프리팹처럼 재사용하고, 보드 구성 설정에서 배치 지점마다 사용할 범퍼 콘텐츠를 선택한 뒤 에디터에서 즉시 결과를 확인하는 방식이다.
- 실제 Godot 4.7.1 인스펙터와 구현을 대조한 결과, 현재는 보드 구성 설정에서 배치 지점의 종류·위치·회전을 수정하는 기능까지 제공한다.
- 각 범퍼 배치 지점에 서로 다른 범퍼 콘텐츠나 장면을 지정하는 참조는 아직 없으며, 현재 2D 목업은 모든 범퍼 지점을 같은 원형 범퍼로 표시한다.
- 따라서 3단계를 완전 충족으로 오해하지 않도록 마스터 계획을 3A 완료·3B 승인 대기로 분리했다. 제품 코드와 씬은 사용자 승인 전 추가 수정하지 않는다.
- 에디터 캡처: `integration/.work/basic-system-foundation/evidence/editor-guide/01-board-overview.png`.
- 보고 방식 피드백에 따라 이후 채팅과 승인된 Confluence 보고는 표준 게임 용어, 문장형 설명, 쉬운 내부 이름 풀이와 에디터 캡처·시험 절차를 함께 제공한다.

## 기획자용 보드 제작 도구 계획 보완

- 사용자는 인스펙터 좌표 입력 대신 2D 화면에서 외곽선 정점, 배치 지점과 플리퍼를 마우스로 움직이는 제작 경험을 요청했다.
- 배치 지점과 실제 오브젝트 배치를 분리하고, 각 지점에 미리 만든 오브젝트 원형을 연결하며 범퍼 종류·최대 내구도 같은 설정을 원형에서 관리하도록 요구했다.
- 플리퍼는 웨이브마다 1~4개를 보드 외곽선을 따라 이동하고 디자인을 교체할 수 있어야 하며, 공은 보드 설정과 제작 화면에서 제외한다.
- 편집기 UX, 기능 책임과 QA를 세 서브 에이전트가 읽기 전용으로 병렬 감사했다. 모두 Godot 4.7.1에서 구현 가능하지만 기존 3B보다 큰 전역 기능 변경이라는 결론을 냈다.
- 마스터 계획을 문서·계약·편집 도구·원형·웨이브/플리퍼·회귀·독립 QA/Confluence의 3B-1~7로 확장했다. 사용자 승인 전에는 제품 코드와 씬을 수정하지 않는다.
- 사용자 지정 Confluence 페이지 `12288002`는 접근 권한과 빈 본문을 확인했다. 기존 내용을 보존하고 실제 캡처·영상·검증 결과가 준비된 뒤에만 갱신한다.
