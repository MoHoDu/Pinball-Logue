## 현재 상태

- `project.godot`은 Godot 4.7, GL Compatibility와 Jolt Physics 3D를 지정하며 메인 씬은 `app/bootstrap/app_root.tscn`이다.
- 앱 루트, 중앙 화면 경로 설정, 단일 내비게이터와 6개 독립 화면 씬이 구현됐다.
- `example_2d.tscn`의 문구 변경은 기존 사용자 변경이므로 이 계획에서 보존한다.
- Web 프리셋과 `deploy` 브랜치용 GitHub Pages 워크플로가 있다. Godot 4.7.1 Web 템플릿 설치와 실제 내보내기·Chromium 로드가 완료됐다.
- 별도 충돌 문서 동기화 초안은 `pinball/objects/.work/collision-system-doc-sync/PLAN.md`에 있으며 충돌 단계에서 통합한다.
- Godot 4.7.1 프로젝트 스캔, 화면 6개×3회 전환 스모크, Web export, WebAssembly·PCK HTTP 200과 브라우저 한 주기 전환은 통과했다.
- 승인된 Pretendard Regular와 공용 Theme를 적용해 Web 한국어 가독성 버그를 수정했고 Chromium에서 여섯 화면을 재검증했다.

## 구현 방향

- 현재 런타임은 3D로 구현한다. 플레이 규칙과 상태는 장면·노드 차원에 의존하지 않게 두고, 공·보드·플리퍼·범퍼만 3D 어댑터로 구현한다.
- 미래 2D 전환은 같은 명령·결과 계약을 소비하는 별도 물리·표현 어댑터 교체로 지원한다. 이번 범위에서 2D와 3D를 동시에 구현하거나 런타임 토글을 만들지 않는다.
- 메인 로비·스테이지 선택·보상·결과는 `Control` 중심의 독립 화면 씬, 웨이브·보스는 `Node3D` 플레이 씬으로 분리한다.
- 앱 조립, 도메인 진행, 핀볼 물리, 스테이지 데이터, 유물, 보상과 UI의 소유권을 기존 폴더 경계대로 유지한다.
- 보드 형상, 범퍼·플리퍼·발사·드레인·유물 슬롯 위치와 모든 조정 수치는 `Resource` 또는 내보내기 속성으로 관리한다.
- 단일 기능 값은 해당 기능 설정에, 둘 이상의 기능이 실제로 공유하는 단위·계약만 `shared/`에 둔다.
- 임시 리소스는 교체 가능한 장면·재질·메시 참조로 주입하고 게임 규칙 코드에 외형을 결합하지 않는다.
- Web 내보내기와 GL Compatibility 제약을 각 물리 단계에서 함께 검증한다.

### 수용 기준

1. Desktop과 Web의 6개 화면에서 현재 한국어 제목·설명·버튼이 네모 글리프 없이 표시된다.
2. 공용 `Theme` 하나를 교체하면 6개 화면의 기본 폰트를 함께 바꿀 수 있다.
3. Web 패키지는 사용자의 OS 폰트 설치 상태에 의존하지 않는다.
4. Godot 4.7.1 프로젝트 스캔, 화면 6개×3회 스모크와 release Web export가 종료 코드 0이다.
5. Chromium 1280×720에서 전체 화면 한 주기, WASM·PCK HTTP 200과 콘솔 오류·경고 0건이 유지된다.
6. 폰트 파일의 출처와 재배포 라이선스가 저장소 내부에서 추적된다.

### 제외 범위와 중단 조건

- 최종 타이포그래피, 폰트 크기 재설계, 다국어 로컬라이제이션과 폰트 서브세팅 최적화는 제외한다.
- 폰트 출처·라이선스가 불명확하거나 Web에서 한국어 글리프가 계속 누락되면 수정 단계를 중단하고 사용자에게 보고한다.
- 폰트 적용이 화면 전환·3D 렌더링·Web export 회귀를 만들면 2단계로 진행하지 않는다.

## 미확정 사항과 가정

- 최신 사용자 지시의 3D 요구가 Confluence `조준·발사 시스템 (Physics2D)`의 노드·API 명세보다 우선한다. 해당 문서는 상태 흐름과 후보 수치만 참고한다.
- UI 화면은 2D `Control`을 사용하고 플레이 공간만 3D로 구성하는 것을 현재 제안한다. 모든 메뉴까지 `Node3D`로 만드는 의미였다면 1단계 승인 전에 수정이 필요하다.
- 2D↔3D 전환 가능성은 도메인 계약과 어댑터 분리로 확보하며 2D 구현 자체는 후속 범위다.
- D-02의 기본 공 수량이 없어 7단계의 실제 실패 흐름은 결정 또는 승인된 테스트용 설정값 없이는 완료할 수 없다.
- D-03~D-06, D-08~D-09는 9~11단계의 유지·초기화·배치·다음 진행에 필요하며 해당 단계 전에 사용자 결정을 요청한다.
- D-07은 공격력 성격 유물·패시브에서 제외하고, 첫 유물은 위치 기반 경로 또는 스코어 효과 후보로 제한한다.
- Confluence의 공·유물 분리 보상 UI는 PL 검토 필요 제안이므로 현재 로컬 확정 기준인 카드 3개를 자동 변경하지 않는다.
- Jolt Physics 3D와 현재 Web 프리셋의 실제 호환성은 미검증이다. 1단계 시험 내보내기에서 실패하면 물리 엔진 선택을 별도 승인 안건으로 되돌린다.
- 검증 실행 파일은 `D:\Godot_v4.7.1-stable_win64.exe\Godot_v4.7.1-stable_win64_console.exe`이며 버전은 `4.7.1.stable.official.a13da4feb`이다.

## 중단·되돌림 조건

- 문서와 구현 경계가 충돌하거나 새 미확정 기획이 필요한 경우 해당 단계에서 중단한다.
- Godot 프로젝트 로드 또는 Web 내보내기가 실패하면 다음 물리 단계로 진행하지 않는다.
