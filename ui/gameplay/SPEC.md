# 공 선택·조준·발사 입력과 플레이 HUD

- 상태: approved
- 관련 결정: `DEC-20260729-01`, D-02

## 표시 정보

- 현재 스코어, 목표 스코어, 남은 목표, 콤보 수와 스코어 배수를 플레이 중 계속 표시한다.
- 목표 스코어에 먼저 도달하면 `목표 달성 · 현재 공 진행 중`을 표시하고 낙하 전까지 입력과 추가 득점을 유지한다.
- 공 슬롯 1~3개의 번호, 공 이름, 남음·선택·소모 상태를 표시한다.
- 현재 상태를 `공 선택`, `공 조준`, `발사 진행`, `낙하 처리`, `발사 종료`의 쉬운 문장으로 표시한다.
- 현재 조준 방식, 조준 방향, 세기와 `Space`의 현재 역할을 표시한다.
- 조준선과 세기 표시는 공·보드 경로를 가리지 않는다.
- 조준선 길이와 `발사 세기` 퍼센트는 내부 입력값이 아니라 실제 발사에 적용될 예상 속도를 기준으로 함께 줄고 늘어난다.
- 예상 속도는 발사 설정의 최소·최대 속도와 선택한 공의 최대 속도 제한을 모두 반영한다. 최소 입력에는 `최소`, 최대 입력에는 `최대`, 공의 제한에 먼저 도달하면 `공 최대`를 표시한다.
- 존재하지 않거나 소모한 슬롯, 잘못된 상태의 입력은 한국어 이유를 짧게 표시한다.
- 현재 발사의 공 패링이 성공하면 오른쪽 HUD에 `PARRY!`를 표시하고 약 0.4초 뒤 자동으로 숨긴다.
- 표시 중 다시 패링되면 마지막 패링 시점부터 표시 시간을 다시 계산한다.
- 현재 활성 발사와 일치하는 패링만 표시하고 이전 발사의 지연된 패링 신호는 무시한다.
- 이번 단계에서는 일반 패링과 정확한 패링을 구분하지 않으며 사운드, 파티클과 화면 흔들림을 추가하지 않는다.

## 입력 경계

- 입력 라우터는 키 누름 이벤트 하나당 명령 하나만 소비하고 즉시 반환한다. 키 해제는 게임 명령으로 처리하지 않는다.
- `direction_keys` 조준 중 방향키를 누르고 있으면 운영체제의 일정한 키 반복 입력을 허용해 각도·세기를 계속 조절한다. `Space`, 공 선택과 플리퍼 선택의 키 반복은 중복 명령을 막기 위해 무시한다.
- 플레이 입력은 전용 입력 액션을 사용한다. UI의 기본 `ui_accept`와 진행 버튼이 `Space`를 함께 소비하지 않는다.
- 공 선택의 `Space`, 조준의 `Space`, 공 진행 중 플리퍼의 `Space`는 같은 프레임에 연쇄 실행되지 않는다.
- 조준 방식 변경은 활성 발사 중인 공에 적용하지 않고 다음 공 조준부터 적용한다.

## 수용 기준

1. 숫자·방향키 선택과 화면의 슬롯·상태가 일치한다.
2. 두 조준 방식에서 허용된 입력만 조준값을 바꾸고 반대 방식 입력은 무시한다.
3. `direction_keys` 조준에서 방향키를 짧게 누르면 한 단계, 누르고 있으면 같은 방향으로 반복 조절된다.
4. `Space`를 연타하거나 UI 버튼에 포커스가 있어도 발사·플리퍼·화면 진행 중 하나만 실행된다.
5. 1280×720에서 공 목록, 현재 조준 방식·세기와 조작 안내가 보드를 가리지 않는다.
6. 같은 방향에서 실제 예상 발사 속도를 높이면 텍스트 퍼센트와 조준선이 같은 비율로 증가하고, 낮추면 같은 비율로 감소한다.
7. 최소 입력·최대 입력과 공 속도 제한에서도 텍스트와 조준선은 실제 적용될 속도와 일치한다.
8. 타격 직후 스코어·콤보·배수와 남은 목표가 같은 결과로 갱신된다.
9. 목표 달성 중에도 현재 공과 플리퍼 조작이 유지되고 낙하 뒤에만 결과가 확정된다.
10. 현재 발사의 패링 성공 시 오른쪽 HUD에 `PARRY!`가 표시되고 약 0.4초 뒤 숨겨지며, 연속 패링은 마지막 패링 기준으로 표시 시간을 갱신한다.
11. 이전 발사의 지연된 패링 신호는 피드백을 표시하지 않고 패링 피드백이 플리퍼·공 물리, 발사·낙하와 스코어 계산을 변경하지 않는다.
