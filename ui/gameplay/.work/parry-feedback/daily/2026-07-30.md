# 2026-07-30 작업 기록

## 구현 내용

- `ui/gameplay/SPEC.md`에 현재 발사 패링의 `PARRY!` 표시, 0.4초 자동 숨김, 연속 패링 시간 갱신과 지연 신호 무시 기준을 먼저 반영했다.
- 웨이브 오른쪽 HUD에 전용 `ParryFeedback` 라벨을 초기 비표시 상태로 추가했다.
- 웨이브 화면 자식으로 0.4초 단발·수동 시작 `ParryFeedbackTimer`를 추가했다.
- 기존 `PlayableBoard2D.flipper_parry_applied` 신호를 웨이브 화면에 연결하고 현재 활성 발사 식별자가 일치할 때만 피드백을 표시했다.
- 매 유효 패링마다 타이머를 다시 시작하고 종료 시 패링 라벨만 숨겼다.
- 기존 플리퍼 물리와 웨이브 반복 스모크 테스트에 신호 인자·중복 방지·표시·갱신·숨김·지연 신호 경계를 추가했다.
