# 재사용 보드 오브젝트 원형

- 상태: approved
- 관련 결정: `DEC-20260728-03`, `DEC-20260729-05`, `DEC-20260729-08`
- 승인 기록: 2026-07-28 사용자가 오브젝트 원형에서 종류·범퍼 종류·내구도를 설정하고 배치 지점에 지정하도록 승인함. 2026-07-29 충돌 기획에 맞춘 네 범퍼 반응, 접촉당 한 타격, 내구도와 안전 복구 구현을 승인함.

## 승인된 데이터

- 모든 원형은 안정적인 원형 ID, 표시 이름, 오브젝트 종류와 최대 내구도를 제공한다.
- 범퍼 원형은 `Normal`, `Bounce`, `Track`, `Shot` 중 하나의 범퍼 종류를 제공한다.
- 벽과 일반 오브젝트는 범퍼 종류를 사용하지 않는다.
- 파괴되지 않는 원형은 별도 표시를 사용하며 최대 내구도 입력을 강요하지 않는다.
- 현재 2D 디자인은 원형과 별도 연결표에서 재사용 장면으로 제공한다.
- 범퍼 원형은 충돌 크기, 타격당 내구도 감소, 기본 점수 근거, 복구 사용 여부·대기·예고·안전 여백과 종류별 반응 설정을 제공한다.
- 현재 내구도, 접촉 잠금, 파괴·복구 상태는 배치 인스턴스마다 독립적이다.
- 범퍼는 기본 점수 근거를 타격 결과에 포함하지만 최종 스코어·콤보·목표 달성을 계산하지 않는다.

## 접촉과 타격

- 최종 2D 어댑터는 공 모양의 현재 위치부터 예상 위치까지 `경로 선행 검사`하고 실제 물리 접촉과 합쳐 하나의 접촉으로 처리한다. 중립 결과 계약은 물리 노드 타입과 분리한다.
- 같은 범퍼와 지속 접촉하는 동안에는 타격, 종류별 효과와 내구도 감소가 한 번만 발생한다.
- 공의 모든 충돌 모양이 범퍼와 기술적 안전 여백을 완전히 벗어난 `분리` 뒤에는 같은 범퍼를 다시 타격할 수 있다.
- 한 논리 범퍼가 여러 충돌 모양을 사용해도 배치 지점 ID 하나를 기준으로 타격을 중복 제거한다.
- 같은 물리 시점의 후보는 최초 접촉 시각이 빠른 순서, 시각이 같으면 배치 지점 ID 순서로 처리한다.

## 범퍼 종류별 반응

| 범퍼 종류 | 승인된 반응 |
| --- | --- |
| `Normal` | 추가 가속 없이 기본 물리 반사를 유지한다. |
| `Bounce` | 기본 반사 속도에 원형의 반동 배율을 적용한다. 기본 배율은 `1.2배`이며 공 원형의 최대 직선 속도를 넘지 않는다. |
| `Track` | 웨이브 배치가 연결한 하나 이상의 경로 지점을 순서대로 모두 통과한 뒤 일반 물리로 복귀한다. |
| `Shot` | 웨이브 배치가 연결한 발사 목표 지점을 향해 설정 속도로 자동 발사한다. 기본 방향 오차는 `0°`다. |

- 경로 지점과 발사 목표 지점은 범퍼 원형이 아니라 보드 레이아웃에 저장하며 2D 제작 화면에서 마우스로 이동한다.
- 범퍼 배치 항목은 경로·목표 지점 ID만 참조한다. 논리 설정과 결과는 `Node2D`, `Node3D`, `RigidBody2D`, `RigidBody3D`를 참조하지 않는다.

## 내구도와 안전 복구

- 유효한 타격 한 번은 기본적으로 현재 내구도를 `1` 감소시키며 원형에서 조정할 수 있다.
- 현재 내구도가 0이 되면 범퍼 충돌을 즉시 비활성화하고 복구 대기를 시작한다. 파괴되지 않는 범퍼는 내구도를 감소시키거나 비활성화하지 않는다.
- 복구 사용의 기본값은 켜짐, 복구 대기의 기본값은 `4초`다. 대기 후에도 공이 안전 영역과 겹치거나 짧은 예상 경로가 안전 영역을 지나면 복구를 미룬다.
- 안전 조건을 만족하면 설정된 시간 동안 복구를 예고한 뒤 최대 내구도로 활성화한다. 예고 중 안전 조건이 깨지면 다시 안전 대기로 돌아간다.
- 새 발사를 준비할 때 모든 범퍼의 현재 내구도·접촉 잠금·복구 타이머를 초기화하고 즉시 최대 내구도 활성 상태로 되돌린다.

## 제품 리소스

- `BoardPlaceableDefinition`은 모든 오브젝트 원형이 공유하는 안정적인 원형 ID, 표시 이름, 오브젝트 종류와 내구도 설정을 제공한다.
- `BumperDefinition`은 공통 원형에 범퍼 종류와 승인된 충돌·내구도·복구·종류별 반응 설정을 더하며 유효하지 않은 수치와 종류를 조립 전에 거부한다.
- 차원 독립 타격 요청·결과는 발사·공·범퍼·배치·접촉·타격 식별자, 보드 평면의 위치·방향·속도, 내구도 전후와 적용 효과를 제공한다.
- 기본 제품 리소스는 일반·반동·경로·발사 범퍼 네 종류를 제공한다. 기본 보드 파일을 시험값으로 직접 변경하지 않고 별도 복제 구성에서 종류별 동작을 검증한다.

## 수용 기준

1. 원형 ID 중복, 빈 표시 이름, 잘못된 종류·범퍼 종류와 유효하지 않은 최대 내구도를 거부한다.
2. 같은 원형을 여러 지점에 배치해도 각 배치 인스턴스가 독립적이다.
3. 원형 교체 시 배치 지점의 위치와 회전이 유지된다.
4. 논리 원형 스크립트가 물리 노드 또는 장면 경로에 의존하지 않고 최종 2D 어댑터가 이를 소비한다.
5. 지속 접촉은 타격과 내구도 감소를 한 번만 만들고 실제 분리 뒤 재접촉은 새 타격을 한 번 만든다.
6. 허용 최대 속도와 여러 입사각에서 범퍼 관통·타격 누락이 없고 종류별 반응 뒤 공 속도 상한을 지킨다.
7. 네 범퍼 종류가 승인된 서로 다른 결과를 만들고 경로·발사 제어가 끝나면 일반 물리로 안전하게 복귀한다.
8. 타격부터 파괴·안전 대기·예고·복구까지 상태가 중복 없이 진행되고 새 발사 준비에서 완전히 초기화된다.

## XP 로우폴리 프로토타입 적용

- 전용 프로토타입은 동일한 2D 범퍼 디자인 1종을 상단·중단 5곳에 재사용하고 범퍼 반동만 사용한다.
- 스코어·내구도·파괴·복구와 Track·Shot 제어는 프로토타입 장면에 연결하지 않지만 기존 원형과 구현은 삭제하지 않는다.
- 유효한 접촉당 반동은 한 번만 적용하고 공 최대 속도를 넘지 않는다. 범퍼는 타격 시 짧은 크기·밝기 피드백만 재생한다.
- 드레인은 중앙 하단의 `Area2D`로 공 한 개당 결과를 한 번만 발생시키며 라이프·실패·화면 전환을 선언하지 않는다.
- 범퍼와 드레인의 충돌 크기·반동과 감지 범위는 별도 복제 설정에서 조정하고 이번 결정으로 숫자를 확정하지 않는다.
