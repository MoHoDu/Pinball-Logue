# 재사용 보드 오브젝트 원형

- 상태: approved
- 관련 결정: `DEC-20260728-03`
- 승인 기록: 2026-07-28 사용자가 오브젝트 원형에서 종류·범퍼 종류·내구도를 설정하고 배치 지점에 지정하도록 승인함

## 승인된 데이터

- 모든 원형은 안정적인 원형 ID, 표시 이름, 오브젝트 종류와 최대 내구도를 제공한다.
- 범퍼 원형은 `Normal`, `Bounce`, `Track`, `Shot` 중 하나의 범퍼 종류를 제공한다.
- 벽과 일반 오브젝트는 범퍼 종류를 사용하지 않는다.
- 파괴되지 않는 원형은 별도 표시를 사용하며 최대 내구도 입력을 강요하지 않는다.
- 현재 2D 디자인은 원형과 별도 연결표에서 재사용 장면으로 제공한다.
- 현재 내구도, 충돌 감소·파괴·복구와 스코어는 후속 충돌 단계가 소유한다.

## 제품 리소스

- `BoardPlaceableDefinition`은 모든 오브젝트 원형이 공유하는 안정적인 원형 ID, 표시 이름, 오브젝트 종류와 내구도 설정을 제공한다.
- `BumperDefinition`은 공통 원형에 범퍼 종류를 더하며, 범퍼가 아닌 오브젝트 종류로 잘못 저장된 설정을 조립 전에 거부한다.
- 기본 샘플은 일반 범퍼, 바운스 범퍼, 벽과 일반 오브젝트를 제공한다. 샘플은 물리 동작이 아니라 기획자가 웨이브 배치를 시험할 수 있는 원형 데이터다.

## 수용 기준

1. 원형 ID 중복, 빈 표시 이름, 잘못된 종류·범퍼 종류와 유효하지 않은 최대 내구도를 거부한다.
2. 같은 원형을 여러 지점에 배치해도 각 배치 인스턴스가 독립적이다.
3. 원형 교체 시 배치 지점의 위치와 회전이 유지된다.
4. 논리 원형 스크립트가 `Node2D`·`Node3D` 또는 장면 경로에 의존하지 않는다.

## 미확정 사항

- 충돌당 내구도 감소량, 0에서의 파괴·비활성화·복구와 초기화 시점은 6단계에서 확정한다.
