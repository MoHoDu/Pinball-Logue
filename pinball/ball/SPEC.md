# 표준 공 원형과 차원 독립 물리 설정

- 상태: approved
- 관련 결정: `DEC-20260729-01`, `DEC-20260729-08`, D-02
- 승인 기록: 2026-07-29 사용자가 목업 웨이브에 공 1~3개를 가져가고 선택·조준·발사 반복을 구현하도록 승인함

## 책임과 경계

- `BallDefinition`은 공 식별자, 표시 이름, 설명, 차원별 디자인 연결 키와 물리 프로필을 제공한다.
- 최종 2D 표현은 공 식별자를 `RigidBody2D` 장면에 연결한다. 논리 원형은 기존 차원 독립 경계를 보존하고 물리 노드와 장면 경로를 직접 참조하지 않는다. 새 3D 공 표현은 계획하지 않는다.
- 목업 웨이브 공 목록은 1~3개다. 낙하한 공은 목록에서 한 번만 소모하며 활성 공은 항상 0개 또는 1개다.
- 공은 웨이브 클리어·실패를 판정하지 않고 선택·생성·물리 상태·안전 제거만 제공한다.

## 표준 공 설정

| 내부 속성 | 인스펙터 표시 | 기본값 | 유효 범위·의미 |
| --- | --- | --- | --- |
| `ball_id` | 공 식별자 | `standard_ball` | 비어 있지 않은 고유 이름 |
| `display_name` | 표시 이름 | `표준 공` | UI와 개발자 모드 표시 |
| `description` | 설명 | `균형 잡힌 기본 물리 공` | 기획자용 역할 설명 |
| `presentation_id` | 디자인 연결 키 | `standard_ball` | 차원별 표현 연결 |
| `radius_board_ratio` | 공 반지름 | `0.025` | 보드 폭 비율 `0.01~0.08` |
| `mass` | 질량 | `1.0` | `0.1~10.0` |
| `bounce` | 반발력 | `0.65` | `0.0~1.0` |
| `friction` | 마찰 | `0.20` | `0.0~1.0` |
| `gravity_scale` | 중력 영향 | `1.0` | `0.0~4.0` |
| `linear_damping` | 직선 감쇠 | `0.05` | `0.0~5.0` |
| `angular_damping` | 회전 감쇠 | `0.05` | `0.0~5.0` |
| `max_linear_speed_board_per_second` | 최대 직선 속도 | `3.0` | 초당 보드 폭 `0.5~10.0` |
| `max_angular_speed_radians` | 최대 회전 속도 | `40.0` | `0.0~100.0 rad/s` |
| `continuous_collision_detection` | 연속 충돌 검사 | `true` | 고속 터널링 방지 |
| `can_sleep` | 물리 휴면 허용 | `false` | 의도치 않은 정지 방지 |

- 공격력, 스코어 배수, 보스 피해, 고유 능력과 성장 수치는 4단계 표준 공에 넣지 않는다.
- 내부 속성명과 `.tres` 직렬화 이름은 영문을 유지하고 Godot 인스펙터에는 위 한국어 이름·설명·단위를 표시한다.

## 수용 기준

1. 공 목록 1·2·3개가 유효하고 0개·4개 이상은 쉬운 한국어 오류로 거부된다.
2. 선택한 공 식별자·설정과 실제 활성 공이 일치하며 중복 생성에도 활성 공이 하나를 넘지 않는다.
3. 최소·최대 물리 설정에서 NaN, 무한 속도와 비정상 정지가 발생하지 않는다.
4. 2D 어댑터는 보드 폭 비율을 픽셀로 변환하고 논리 설정에 2D 물리 노드 참조를 넣지 않는다.
5. 낙하 결과가 확정된 공은 한 번만 제거·소모되며 다음 공 선택이 가능하다.

## XP 로우폴리 프로토타입 적용

- 전용 프로토타입에서는 공 선택·라이프·실패를 연결하지 않고 활성 공 한 개를 우측 투입 레인에서 자동으로 시작한다.
- 드레인 결과 뒤 짧은 대기 후 같은 공 한 개를 다시 투입하며, 삭제·생성 전환 중 활성 공이 둘이 되지 않아야 한다.
- 공의 중력·반발·마찰·감쇠·속도 상한은 별도 복제 설정에서 조정하고 이번 결정으로 숫자를 확정하지 않는다.
- 최종 스프라이트는 `Resources/Art/xp_low_poly_pinball/`의 2D 알파 PNG를 사용하며 최대 속도에서도 보드와 구분돼야 한다.
