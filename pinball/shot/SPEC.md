# 한 발사 생명주기와 낙하 반복

- 상태: approved
- 관련 결정: `DEC-20260729-01`, D-01, D-02
- 승인 기록: 2026-07-29 사용자가 공 선택→조준→발사→플리퍼→낙하 반복과 낙하 뒤 목표 판정을 승인함

## 상태 흐름

```text
공 선택
→ 선택 확정
→ 공 조준
→ 발사 진행
→ 낙하 처리
→ 발사 결과 확정
→ 남은 공이 있으면 공 선택
```

- 각 발사는 고유 발사 식별자를 사용한다.
- 활성 발사는 동시에 하나만 존재하며 낙하 또는 상위 종료 조건 중 먼저 승인된 이유 하나로만 끝난다.
- 이전 발사의 지연 충돌·낙하 이벤트는 현재 발사 결과를 바꾸지 않는다.
- 4단계는 스코어와 웨이브 성공·실패를 계산하지 않고 최종 결과와 남은 공 목록만 공개한다.
- 7단계에서 목표를 먼저 달성해도 현재 발사는 중단하지 않는다. 낙하 후 마지막 이벤트까지 반영한 스코어로 클리어·다음 공·실패를 판단한다.

## 종료 이유

- `drain`: 드레인 영역 낙하
- `out_of_bounds`: 보드 밖 안전 종료 영역 진입
- `cancelled`: 조립 계층이 승인한 명시적 취소

## 수용 기준

1. 중복 시작·종료 요청에도 발사 하나가 정확히 한 번 시작하고 한 번 종료된다.
2. 낙하한 공은 한 번만 소모되며 남은 공이 있으면 공 선택 상태로 돌아간다.
3. 공을 모두 소모하면 반복을 종료하지만 4단계에서는 스테이지 실패를 직접 선언하지 않는다.
4. 결과의 공·발사 식별자와 실제 선택·활성 공이 일치한다.
5. 목표 달성과 낙하가 같은 물리 틱에 발생해도 7단계 최종 판정은 낙하 결과 반영 뒤 한 번만 실행할 수 있다.
