# 교체 가능한 공 조준과 발사

- 상태: approved
- 관련 결정: `DEC-20260729-01`
- 승인 기록: 2026-07-29 사용자가 방향키·마우스 조준 방식을 설정으로 교체하고 두 방식 모두 `Space`로 발사하도록 승인함

## 상태별 입력

| 상태 | 숫자키 | 방향키 | `Space` | 마우스 |
| --- | --- | --- | --- | --- |
| 공 선택 | `1`·`2`·`3` 슬롯 직접 선택 | 좌우로 남은 공 순환 | 선택 확정 | UI 선택 가능 |
| 공 조준·방향키 방식 | 무시 | 좌우 각도·상하 세기, 길게 누르면 반복 조절 | 발사 | 무시 |
| 공 조준·마우스 방식 | 무시 | 무시 | 발사 | 방향·거리로 각도·세기 |
| 공 진행 중 | 무시 | 플리퍼 선택 명령 | 플리퍼 작동 명령 | 조준 종료 |
| 낙하 처리 | 무시 | 무시 | 무시 | 무시 |

- `Space`는 현재 상태가 정확히 하나의 명령으로 해석되며 같은 입력이 선택 확정·발사·플리퍼 작동을 동시에 실행하지 않는다.
- 방향키 조준 중에는 최초 누름과 길게 누를 때 발생하는 반복 입력을 모두 각도·세기 조절에 사용한다. `Space` 반복 입력은 발사 중복을 막기 위해 사용하지 않는다.
- 존재하지 않거나 소모된 공 슬롯, 선택 전 확정, 조준 전 발사와 활성 공 중 재발사는 한국어 이유를 포함한 거부 결과를 반환한다.

## 발사 설정

| 내부 속성 | 인스펙터 표시 | 기본값 | 의미 |
| --- | --- | --- | --- |
| `aim_mode` | 조준 방식 | `mouse` | `direction_keys` 또는 `mouse` |
| `default_aim_angle_degrees` | 기본 조준 각도 | `0.0°` | 발사 지점 안쪽 기준 |
| `minimum_aim_angle_degrees` | 최소 조준 각도 | `-45.0°` | 허용 부채꼴 왼쪽 경계 |
| `maximum_aim_angle_degrees` | 최대 조준 각도 | `45.0°` | 허용 부채꼴 오른쪽 경계 |
| `keyboard_angle_step_degrees` | 방향키 각도 변화량 | `2.0°` | 좌우 입력 1회당 변화 |
| `keyboard_strength_step` | 방향키 세기 변화량 | `0.05` | 상하 입력 1회당 변화 |
| `default_strength` | 기본 발사 세기 | `0.60` | `0.0~1.0` |
| `minimum_speed_board_per_second` | 최소 발사 속도 | `1.0` | 초당 보드 폭 |
| `maximum_speed_board_per_second` | 최대 발사 속도 | `2.5` | 초당 보드 폭 |
| `mouse_max_distance_board_ratio` | 마우스 최대 조준 거리 | `0.35` | 최대 세기가 되는 보드 폭 비율 |
| `aim_guide_length_board_ratio` | 조준선 길이 | `0.28` | 최대 세기에서 사용하는 보드 폭 비율 |

## 차원 독립 커맨드와 전략

- `LaunchCommand`는 요청·발사·공·발사 지점 식별자, 정규화 보드 평면 방향과 `0~1` 세기를 전달한다.
- `LaunchVelocityStrategy`는 조준 방식과 무관하게 발사 설정을 검증하고 보드 폭/초 단위 초기 속도를 계산한다.
- `BallPhysicsAdapter`는 보드 평면 위치·방향과 속도를 현재 2D 또는 미래 3D 물리 공간으로 변환한다.
- 4단계는 `RigidBody2D` 어댑터와 계약 검증용 가짜 어댑터만 구현한다. `RigidBody3D` 구현과 동시 차원 토글은 제외한다.

## 수용 기준

1. 설정 하나를 교체하면 같은 공·보드에서 방향키와 마우스 조준을 코드 변경 없이 사용할 수 있다.
2. 같은 정규화 방향·세기는 두 조준 방식에서 같은 `LaunchCommand`와 보드 평면 초기 속도를 만든다.
3. `Space` 연타와 상태 전환 경계에서 공 생성·선택 확정·발사 힘이 중복되지 않는다.
4. 최소·최대 각도와 세기는 범위 안으로 제한되며 실제 초기 속도가 계산 결과와 일치한다.
5. 발사 계약과 전략은 `Node2D`, `Node3D`, `RigidBody2D`, `RigidBody3D`를 참조하지 않는다.
6. 방향키 조준에서 방향키를 길게 누르면 같은 방향으로 반복 조절되고, 키를 떼면 조절이 끝난다.
