# 플리퍼 원형과 외곽선 배치

- 상태: approved
- 관련 결정: `DEC-20260728-03`, `DEC-20260729-02`, `DEC-20260729-08`
- 승인 기록: 2026-07-28 사용자가 플리퍼를 1~4개 배치하고 외곽선을 따라 마우스로 이동하며 디자인을 교체하도록 승인함. 2026-07-29 방향키별 조작 대상을 왼쪽만·오른쪽만·좌우 쌍으로 구성하고 좌우 쌍을 함께 작동하도록 승인함.

## 승인된 동작

- 플리퍼 원형은 안정적인 ID, 표시 이름과 교체 가능한 현재 2D 디자인을 제공한다.
- 한 웨이브에는 플리퍼가 1~4개 존재한다.
- 플리퍼 위치는 보드 외곽선의 변과 변 위 위치 비율로 저장한다.
- 플리퍼를 마우스로 이동하면 가장 가까운 외곽선에 붙고 기본 방향은 보드 안쪽을 향한다.
- 외곽선 정점이 바뀌어도 플리퍼는 외곽선에 붙어 있어야 한다.
- 실제 선택·작동·복귀·패링 물리는 5단계가 소유한다.
- 보드 중심에서 각 플리퍼 배치 위치로 향하는 상대 방향을 비교해 위·아래·왼쪽·오른쪽 입력 후보를 계산한다.
- 플리퍼가 2개면 두 위치의 주 분리축을 우선해 가로 배치는 좌·우, 세로 배치는 상·하로 배정한다. 1·3·4개는 위치와 방향키의 총 각도 오차가 가장 작은 고유 조합을 선택한다. 같은 방향키를 둘 이상의 플리퍼에 지정하지 않는다.
- 보드 제작 화면은 각 플리퍼에 배정된 `↑`·`↓`·`←`·`→`를 표시하고, 위치 변경 뒤 배정을 다시 계산한다. 중복·모호한 배정을 해결할 수 없으면 저장·조립을 거부한다.

## 선택·작동·공 패링

- 공 진행 중 방향키 하나는 `플리퍼 조작 대상` 하나를 선택한다. 조작 구성은 `왼쪽만`, `오른쪽만`, `좌우 쌍` 중 하나다.
- 유효한 웨이브에는 선택된 플리퍼 조작 대상이 항상 하나 존재한다. 최초 선택은 사용 가능한 대상 중 `아래 → 왼쪽 → 오른쪽 → 위` 순으로 자동 결정하고 발사·낙하 전환에서도 유지한다.
- 사용 가능한 대상이 없는 방향을 눌러도 현재 선택은 유지하며 `선택 플리퍼: 없음` 상태로 돌아가지 않는다.
- 왼쪽만·오른쪽만은 해당 배치 지점 하나, 좌우 쌍은 서로 다른 왼쪽·오른쪽 배치 지점 두 개를 참조한다. 같은 플리퍼를 둘 이상의 조작 대상에 중복 포함하지 않는다.
- 방향키는 실제 플리퍼가 아니라 조작 대상마다 고유하다. 단일 대상은 해당 위치, 좌우 쌍은 두 위치의 중점을 보드 중심과 비교해 상·하·좌·우 중 하나를 자동 배정한다.
- `Space` 한 번으로 선택 대상이 `대기 → 작동 → 유지 → 복귀 → 대기`를 진행한다. 왼쪽만·오른쪽만은 한 개, 좌우 쌍은 두 개가 같은 물리 틱에 작동한다.
- 작동 중 추가 `Space`와 키 반복은 중복 힘을 만들지 않는다. 다음 작동은 선택 대상이 대기로 복귀한 뒤 허용한다.
- 왼쪽 역할과 오른쪽 역할은 서로 거울 방향으로 보드 안쪽을 쓸어 올린다. 최종 방향은 배치 위치와 보드 중심으로 결정하고 기획자가 시계·반시계를 직접 계산하지 않는다.
- 작동 시작 뒤 설정된 공 패링 시간 안의 첫 공 접촉만 추가 힘을 받는다. 한 작동 명령에서 추가 힘은 최대 한 번이며 공 물리 설정의 최대 직선 속도를 넘지 않는다.
- 작동 명령·상태·접촉 결과는 보드 평면 기준 차원 독립 계약으로 제공한다. 최종 런타임은 2D 물리 어댑터를 사용하고 새 3D 어댑터는 계획하지 않는다.

## 편집 가능한 물리 설정

- 플리퍼 길이·너비, 작동 회전 각도, 작동 시간, 유지 시간, 복귀 시간, 기본 타격 힘, 공 패링 시간과 공 패링 힘 배수는 플리퍼 물리 설정으로 노출한다.
- 내부 GDScript와 `.tres` 속성명은 영문으로 유지하고 Godot 인스펙터와 미래 개발자 모드에는 한국어 이름·설명·단위·범위를 표시한다.
- 기본 설정을 직접 바꾸지 않고 복제본으로 시험한다.

## 제품 리소스

- `FlipperDefinition`은 플리퍼 원형의 안정적인 원형 ID, 표시 이름과 내구도 설정을 제공한다.
- 표준 플리퍼와 소형 플리퍼 샘플은 서로 다른 원형 ID를 사용한다. 현재 2D 디자인은 이 논리 원형에 넣지 않고 별도의 디자인 연결표에서 선택한다.

## 수용 기준

1. 1·2·3·4개 구성이 저장·조립되고 0·5개는 쉬운 한국어 오류와 함께 거부된다.
2. 모서리를 넘어 이동해도 끊김이 없고 외곽선 변경 뒤에도 유효한 위치·방향을 유지한다.
3. 디자인 원형 교체가 지점 위치를 바꾸거나 이전 디자인을 남기지 않는다.
4. 논리 원형과 배치 데이터는 차원 노드에 의존하지 않는다.
5. 플리퍼 1~4개에서 각 방향키가 최대 한 `플리퍼 조작 대상`에만 배정되고, 위치 변경 뒤 상대 방향을 다시 반영한다.
6. 왼쪽만·오른쪽만·좌우 쌍 조작 대상이 저장·조립되고 좌우 쌍은 같은 물리 틱에 함께 작동한다.
7. 작동·유지·복귀 뒤 재사용할 수 있고 연타가 중복 힘·입력 잠김·복귀 불능을 만들지 않는다.
8. 이른·정확한·늦은 입력의 공 각도·속도 또는 거리에 측정 가능한 차이가 있고 패링 추가 힘은 한 작동에서 한 번만 적용된다.
9. 차원 독립 명령·상태에 2D·3D 노드·장면 참조가 없고 현재 2D 어댑터가 실제 플리퍼 충돌을 제공한다.
10. 최초 선택은 `아래 → 왼쪽 → 오른쪽 → 위` 우선순위를 따르고 발사·낙하·잘못된 방향 입력 뒤에도 유효한 선택 하나를 유지한다.

## XP 로우폴리 프로토타입 적용

- 전용 프로토타입은 하단 플리퍼 2개만 사용하고 왼쪽은 `A` 또는 `←`, 오른쪽은 `D` 또는 `→`로 직접 작동한다.
- 키를 누르는 동안 작동 상태를 유지하고 놓으면 복귀하는 입력은 전용 얇은 조립 계층에서 기존 `Flipper2D` 공개 동작으로 변환한다. 기존 웨이브의 방향 선택·`Space` 계약은 삭제하지 않는다.
- 왼쪽 피벗이 명확한 2D 알파 PNG 하나를 사용하고 오른쪽은 수평 반전해 같은 제품군과 광원 방향을 유지한다.
- 회전 각도·작동·복귀 시간과 타격 힘은 별도 복제 설정에서 조정하고 이번 결정으로 숫자를 확정하지 않는다.
