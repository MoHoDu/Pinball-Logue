# 플리퍼 원형과 외곽선 배치

- 상태: approved
- 관련 결정: `DEC-20260728-03`
- 승인 기록: 2026-07-28 사용자가 플리퍼를 1~4개 배치하고 외곽선을 따라 마우스로 이동하며 디자인을 교체하도록 승인함

## 승인된 동작

- 플리퍼 원형은 안정적인 ID, 표시 이름과 교체 가능한 현재 2D 디자인을 제공한다.
- 한 웨이브에는 플리퍼가 1~4개 존재한다.
- 플리퍼 위치는 보드 외곽선의 변과 변 위 위치 비율로 저장한다.
- 플리퍼를 마우스로 이동하면 가장 가까운 외곽선에 붙고 기본 방향은 보드 안쪽을 향한다.
- 외곽선 정점이 바뀌어도 플리퍼는 외곽선에 붙어 있어야 한다.
- 실제 선택·작동·복귀·패링 물리는 5단계가 소유한다.

## 제품 리소스

- `FlipperDefinition`은 플리퍼 원형의 안정적인 원형 ID, 표시 이름과 내구도 설정을 제공한다.
- 표준 플리퍼와 소형 플리퍼 샘플은 서로 다른 원형 ID를 사용한다. 현재 2D 디자인은 이 논리 원형에 넣지 않고 별도의 디자인 연결표에서 선택한다.

## 수용 기준

1. 1·2·3·4개 구성이 저장·조립되고 0·5개는 쉬운 한국어 오류와 함께 거부된다.
2. 모서리를 넘어 이동해도 끊김이 없고 외곽선 변경 뒤에도 유효한 위치·방향을 유지한다.
3. 디자인 원형 교체가 지점 위치를 바꾸거나 이전 디자인을 남기지 않는다.
4. 논리 원형과 배치 데이터는 차원 노드에 의존하지 않는다.
